## ✨ What is FluentCart?

**FluentCart** is a powerful, lightweight, and modern e-commerce solution for WordPress. Built for speed and simplicity, it empowers you to create beautiful online stores that convert visitors into customers—without the bloat.

Whether you're selling physical products, digital downloads, subscriptions, or licensed software, FluentCart provides everything you need to build and scale your online business.

## 🚀 Key Features

### 💰 **Sell Anything, Beautifully**
- 📦 **Physical Products** - Manage inventory, shipping, and variations
- 💾 **Digital Downloads** - Secure file delivery with download limits
- 🔄 **Subscriptions** - Recurring revenue with flexible billing cycles
- 🔑 **Licensed Software** - Software licensing with activation management
- 🎨 **Product Blocks & Templates** - Design your store with WordPress blocks

### 📈 **Built-in Marketing Tools**
- 🎯 **Order Bumps** - Increase AOV with one-click upsells at checkout
- 🎟️ **Coupon System** - Powerful discounts and promotional campaigns
- 📊 **Analytics & Reports** - Track sales, revenue, and customer behavior

### 🔌 **Seamless Integrations**
- ✉️ **FluentCRM** - Marketing automation and email sequences
- 👥 **FluentCommunity** - Members-only content and access control
- 💳 **Payment Gateways** - Stripe, PayPal, Paddle, and more
- 🌍 **Global Ready** - Tax management

### ⚡ **Performance & Experience**
- 🚄 **Lightning Fast** - Optimized for speed and performance
- 📱 **Mobile Optimized** - Responsive design for all devices
- 🎯 **Conversion Focused** - Streamlined checkout that converts

### 🌍 **Global Commerce**
- 💸 **Tax & Duties** - Automated tax calculation with EU VAT support
- 🚚 **Flexible Shipping** - Multiple shipping methods and zones

## 📦 Quick Start

### Installation

1. **Download FluentCart** from the WordPress plugin repository or your account
2. **Upload** the plugin to your WordPress site
3. **Activate** FluentCart from the Plugins menu
4. **Run** the setup wizard to configure your store
5. **Create** your first product and start selling!

```bash
# Or install via WP-CLI
wp plugin install fluent-cart --activate
```

### Your First Product

Creating your first product takes just minutes:

1. Navigate to **FluentCart → Products**
2. Click **Add New Product**
3. Enter product details (name, price, description)
4. Set up payment gateways in **Settings → Payments**
5. Configure shipping if needed
6. Publish and start selling! 🎉
